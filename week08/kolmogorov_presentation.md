# 第 3 頁：什麼是 Kolmogorov Complexity？

## 核心定義

> 一個字串的 Kolmogorov Complexity 是能夠生成該字串的**最短程序的長度**

## 直觀理解

- 簡單規律的字串 → 低複雜度
- 隨機無序的字串 → 高複雜度

**範例：**
- `"000000000000"` → 低複雜度（可用「印12個0」描述）
- `"a8f3k9m2x7q1"` → 高複雜度（沒有簡短描述）

---

# 第 4 頁：數學定義

## 形式化表示

對於字串 x，其 Kolmogorov Complexity 定義為：

**K(x) = min { |p| : U(p) = x }**

其中：
- `K(x)` = 字串 x 的 Kolmogorov Complexity
- `p` = 程序（program）
- `|p|` = 程序 p 的長度（位元數）
- `U` = 通用圖靈機（Universal Turing Machine）
- `U(p) = x` = 程序 p 在 U 上執行後輸出 x

---

# 第 5 頁：簡單範例

## 範例 1：重複字串

**字串：** `"AAAAAAAAAA"` (10個A)

**直接表示：** 10 個字符 = 80 bits
**壓縮表示：** `"print('A' * 10)"` ≈ 20 bits

**K("AAAAAAAAAA") ≈ 20 bits**

---

## 範例 2：隨機字串

**字串：** `"8k3mQ9xL2p"`

**直接表示：** 10 個字符 = 80 bits
**最短程序：** 基本上就是 `"print('8k3mQ9xL2p')"` ≈ 80 bits

**K("8k3mQ9xL2p") ≈ 80 bits**

# 第 6 頁：關鍵性質

## 不可壓縮性定理

**存在不可壓縮的字串**
- 對於長度為 n 的字串，至少有一個字串 x 使得 K(x) ≥ n
- 這樣的字串被稱為「隨機字串」

## 不變性定理

**與程式語言選擇無關**（相差常數）
- K_Python(x) ≈ K_Java(x) ± C
- C 是與語言相關的常數

## 上界性質

**K(x) ≤ |x| + c**
- 任何字串的複雜度不會遠超過其長度

# 第 8 頁：條件複雜度

## K(x|y)：給定 y 時 x 的複雜度

**定義：** 當已知 y 時，生成 x 所需的最短程序長度

**範例：**

已知 y = "今天天氣"
- K("今天天氣很好" | y) < K("今天天氣很好")
- 因為可以用「加上'很好'」來描述

## 互信息

**I(x:y) = K(y) - K(y|x)**
- 測量 x 和 y 之間共享的資訊量

---

# 第 9 頁：不可計算性

## 重大問題：K(x) 是不可計算的！

**Kolmogorov Complexity 無法精確計算**

### 證明概念（停機問題）

如果能計算 K(x)，則：
1. 可以列舉所有短於 n 的程序
2. 找出第一個 K(x) > n 的字串
3. 但這個找尋過程本身就是一個短程序
4. 矛盾！該字串應該有更短的描述

**結論：** 我們只能「近似」Kolmogorov Complexity

---

# 第 10 頁：實務近似方法

## 使用壓縮演算法

由於無法精確計算，我們使用實際壓縮器來近似：

### 常用壓縮演算法

**gzip / zlib**
- 基於 LZ77 + Huffman 編碼
- 快速，適合一般用途

**bzip2**
- 基於 Burrows-Wheeler 轉換
- 壓縮率較高

**LZMA / 7z**
- 更高的壓縮率
- 計算成本較高

**近似：** K(x) ≈ |compressed(x)|

# 第 11 頁：標準化壓縮距離 (NCD)

## 測量兩個物件的相似度

**定義：**

**NCD(x, y) = [C(xy) - min(C(x), C(y))] / max(C(x), C(y))**

其中：
- C(x) = x 的壓縮長度
- C(xy) = x 和 y 連接後的壓縮長度

## 特性

- **0 ≤ NCD ≤ 1**
- **NCD = 0** → x 和 y 完全相同
- **NCD = 1** → x 和 y 完全不相關
- **對稱性：** NCD(x,y) = NCD(y,x)

---

# 第 12 頁：NCD 應用範例

## 文本相似度分析

**文本 1：** "機器學習是人工智慧的一個分支"
**文本 2：** "機器學習屬於人工智慧領域"
**文本 3：** "今天天氣很好"

**結果：**
- NCD(文本1, 文本2) ≈ 0.3 ← 主題相似
- NCD(文本1, 文本3) ≈ 0.9 ← 主題不同

## 優勢

- **無需訓練**：不需要預訓練模型
- **語言無關**：適用於任何語言
- **通用性**：可用於文本、圖像、音頻等

# 第 13 頁：在 NLP 中的應用

## 1. 文本分類

使用 NCD 計算文本與各類別代表文本的距離
- 將文本分配給距離最小的類別
- 無需特徵工程

## 2. 語言檢測

比較文本與不同語言語料庫的 NCD
- 自動識別未知文本的語言

## 3. 抄襲檢測

計算文檔之間的 NCD
- 高相似度可能表示抄襲

## 4. 文本摘要評估

評估摘要保留了多少原文資訊
- K(摘要|原文) 應該很小

# 第 14 頁：在機器學習中的應用

## 模型選擇與最小描述長度 (MDL)

**原理：** 選擇能最簡潔描述數據的模型

**MDL = K(模型) + K(數據|模型)**

## 正則化的理論基礎

**奧坎剃刀原理形式化**
- 簡單模型優先（除非數據強烈支持複雜模型）
- L1/L2 正則化的理論依據

## 特徵選擇

選擇能最有效壓縮目標變量的特徵
- 高互信息 I(特徵:目標) 的特徵更重要

# 第 15 頁：異常檢測

## 基於複雜度的異常檢測

**正常數據：** 低複雜度（有規律）
**異常數據：** 高複雜度（隨機、不規律）

### 方法

1. 計算數據集中每個樣本的 K(x)
2. 計算平均複雜度和標準差
3. 標記複雜度異常高的樣本

### 應用場景

- 網絡入侵檢測
- 工業設備異常監控
- 醫療診斷輔助

# 第 17 頁：實作考量

## Python 實作要點

```python
import zlib

def approximate_k(text):
    """近似計算 Kolmogorov Complexity"""
    return len(zlib.compress(text.encode('utf-8')))

def ncd(text1, text2):
    """計算標準化壓縮距離"""
    c1 = approximate_k(text1)
    c2 = approximate_k(text2)
    c12 = approximate_k(text1 + text2)
    return (c12 - min(c1, c2)) / max(c1, c2)
```

## 注意事項

- 選擇合適的壓縮演算法
- 處理短文本時的不穩定性
- 計算成本 vs 準確度權衡

# 第 18 頁：限制與挑戰

## 理論限制

**不可計算性**
- 只能使用近似方法
- 不同壓縮器給出不同結果

**常數依賴性**
- 與選擇的通用機器有關
- 實務上影響不大（對於長字串）

## 實務挑戰

**短字串問題**
- 壓縮演算法開銷
- 結果不穩定

**計算成本**
- 高級壓縮器很慢
- 大數據集處理困難

**解釋性**
- 黑盒性質
- 難以解釋為何兩個物件相似
